## 🏗️ 整体架构

### 简单比喻

想象你要分析一份 Excel 表格，SheetBrain 就像一个**三步骤的智能助手**：

1. **理解阶段**：助手先"看"一遍表格，了解里面有什么数据
2. **执行阶段**：助手写代码、运行代码，算出答案
3. **验证阶段**：助手检查自己的答案对不对，如果不对就回去重做

这三个阶段会**循环执行**，直到答案通过验证，或者达到最大尝试次数。

### 流程图

```
用户问题："这个月的总销售额是多少？"
         ↓
┌─────────────────────────────────────┐
│  阶段1：理解 (Understanding)        │
│  - 看表格结构                        │
│  - 理解问题意图                      │
│  - 制定分析策略                      │
└─────────────────────────────────────┘
         ↓
┌─────────────────────────────────────┐
│  阶段2：执行 (Execution)             │
│  - 写 Python 代码                    │
│  - 运行代码计算                      │
│  - 得到初步答案                      │
└─────────────────────────────────────┘
         ↓
┌─────────────────────────────────────┐
│  阶段3：验证 (Validation)            │
│  - 检查答案是否合理                  │
│  - 发现错误？→ 回到阶段2重做         │
│  - 答案正确？→ 输出最终结果          │
└─────────────────────────────────────┘
```

## 📖 第一阶段：理解模块（UnderstandingModule）

### 位置

`src/backend/modules/understanding.py`

### 作用

**理解模块就像是一个"分析师"**，它的任务是：

1. 看一遍 Excel 表格的结构
2. 理解用户的问题是什么意思
3. 制定一个分析计划

### 工作流程

```python
def analyze(self, user_question, table_image=None):
    # 1. 创建提示词（告诉 AI 要做什么）
    messages = self._create_multimodal_prompt(...)
  
    # 2. 调用 AI 进行分析
    understanding_output = self._get_llm_response(messages)
  
    # 3. 返回分析结果
    return understanding_output
```

### 详细解释

**1. 创建提示词（`_create_multimodal_prompt`）**

这个函数会创建一个"任务描述"，告诉 AI：

- 用户问了什么问题
- Excel 表格里有什么数据
- 需要分析什么

**示例提示词：**

```
你是一个 Excel 数据分析专家。我需要你分析以下表格内容来回答用户的问题。

用户问题：这个月的总销售额是多少？

Excel 表格内容：
- Sheet1: 包含销售数据
  - A列：日期
  - B列：产品名称
  - C列：销售额
  - 共 100 行数据

你的任务：
1. 分析表格结构
2. 理解用户问题的意图
3. 制定分析策略
```

**2. 调用 AI（`_get_llm_response`）**

把提示词发送给 OpenAI API，AI 会返回分析结果，比如：

```
分析结果：
- 表格包含销售数据，时间范围是 2024年1月
- 用户想知道总销售额
- 需要：筛选1月的数据，然后对销售额列求和
```

## 💻 第二阶段：执行模块（ExecutionModule）

### 位置

`src/backend/modules/execution.py`

### 作用

**执行模块就像是一个"程序员"**，它的任务是：

1. 根据理解模块的分析，写 Python 代码
2. 运行这些代码
3. 得到答案

### 工作流程

```python
def run(self, understanding_output, user_question):
    # 1. 创建系统提示词（告诉 AI 如何写代码）
    system_prompt = self._get_system_prompt()
  
    # 2. 多轮对话循环
    for turn in range(max_turns):
        # AI 生成代码或答案
        response = self._get_llm_response(...)
      
        # 如果 AI 写了代码，就执行它
        if "```python" in response:
            code = self._extract_code(response)
            result = self._execute_code(code)
      
        # 如果 AI 给出最终答案，就返回
        if "Final Answer:" in response:
            return result
```

### 详细解释

**1. 系统提示词（`_get_system_prompt`）**

这个提示词告诉 AI：

- 你可以使用哪些工具（如 `inspector`, `get_sheet` 等）
- 如何写代码
- 代码格式要求

**示例：**

```
你是一个 Excel 数据分析专家，可以使用以下工具：
- inspector("A1:C10")：读取单元格数据
- get_sheet("Sheet1")：获取工作表
- pandas：处理数据

你的回答格式：
**Thought:** 你的思考过程
```python
# 你的代码
```

或者

**Thought:** 你的思考过程
Final Answer: 你的答案

```

**2. 代码执行（`_execute_code`）**

当 AI 生成代码后，系统会：
```python
def _execute_code(self, code):
    # 在安全的环境中运行代码
    exec(code, self.code_globals, self.code_locals)
  
    # 获取执行结果
    result = self.code_locals.get('result', None)
    return result
```

**示例：**

```python
# AI 生成的代码
import pandas as pd
sheet = get_sheet("Sheet1")
data = inspector("A1:C100", "Sheet1")
df = pd.DataFrame(data[1:], columns=data[0])
total = df['销售额'].sum()
result = f"总销售额是 {total} 元"
```

**3. 多轮对话**

执行模块支持多轮对话，AI 可以：

- 第一轮：先读取数据
- 第二轮：处理数据
- 第三轮：计算并给出答案

## ✅ 第三阶段：验证模块（ValidationModule）

### 位置

`src/backend/modules/validation.py`

### 作用

**验证模块就像是一个"质检员"**，它的任务是：

1. 检查执行模块给出的答案是否正确
2. 发现错误就给出改进建议
3. 如果答案正确，就批准通过

### 工作流程

```python
def reflect(self, execution_result, user_question, understanding_output):
    # 1. 创建验证提示词
    messages = self._create_validation_prompt(...)
  
    # 2. 调用 AI 进行验证
    validation_analysis = self._get_llm_response(messages)
  
    # 3. 解析验证结果
    validation_result = self._parse_validation_response(validation_analysis)
  
    # 4. 返回验证结果
    return validation_result
```

### 详细解释

**1. 验证提示词（`_create_validation_prompt`）**

告诉 AI 要检查什么：

```
请验证以下答案是否正确：

用户问题：这个月的总销售额是多少？

理解模块的分析：
- 需要计算1月的总销售额

执行模块的答案：
- 总销售额是 100,000 元

请检查：
1. 答案是否回答了用户的问题？
2. 计算是否正确？
3. 是否有遗漏的数据？
4. 答案格式是否合理？

请给出：
- VALIDATION_STATUS: PASSED 或 FAILED
- CONFIDENCE_SCORE: 0.0 到 1.0
- ISSUES_FOUND: 发现的问题列表
- IMPROVEMENT_FEEDBACK: 改进建议
```

**2. 验证结果解析（`_parse_validation_response`）**

从 AI 的回复中提取结构化信息：

```python
{
    "validation_passed": True/False,  # 是否通过
    "confidence_score": 0.85,          # 置信度
    "issues_found": [...],             # 发现的问题
    "improvement_feedback": "..."      # 改进建议
}
```

## 🔄 完整流程示例

### 场景：用户问"这个月的总销售额是多少？"

#### 步骤1：初始化 SheetBrain

```python
agent = SheetBrain(excel_path="sales.xlsx")
# 系统加载 Excel 文件，创建三个模块
```

#### 步骤2：调用 run 方法

```python
result = agent.run("这个月的总销售额是多少？")
```

#### 步骤3：理解阶段

```
📖 [STAGE 1] UNDERSTANDING MODULE
- 分析 Excel 结构：发现"日期"列和"销售额"列
- 理解问题：需要计算1月的总销售额
- 制定策略：筛选1月数据，然后求和
```

#### 步骤4：执行阶段（第1轮）

```
💻 [ITERATION 1] EXECUTION MODULE
- AI 思考：需要先读取数据
- AI 写代码：
  ```python
  data = inspector("A1:C100")
  # 处理数据...
```

- 执行代码：得到初步结果

```

#### 步骤5：验证阶段（第1轮）
```

🔍 [ITERATION 1] VALIDATION MODULE

- 检查答案：发现只计算了部分数据
- 问题：遗漏了某些行
- 建议：需要检查所有数据行
- 结果：FAILED，需要重做

```

#### 步骤6：执行阶段（第2轮）
```

💻 [ITERATION 2] EXECUTION MODULE

- 收到验证反馈：需要检查所有数据
- AI 重新写代码：
  ```python
  # 这次确保读取所有数据
  data = inspector("A1:C200")  # 读取更多行
  # 重新计算...
  ```
- 执行代码：得到新结果

```

#### 步骤7：验证阶段（第2轮）
```

🔍 [ITERATION 2] VALIDATION MODULE

- 检查答案：这次计算了所有数据
- 验证：答案合理，计算正确
- 结果：PASSED ✅

```

#### 步骤8：返回最终结果
```python
{
    "success": True,
    "answer": "这个月的总销售额是 150,000 元",
    "confidence_score": 0.95,
    "validation_passed": True,
    "total_iterations": 2
}
```

## 🎓 总结

### 核心思想

SheetBrain 采用了**"理解-执行-验证"**的三阶段架构，通过**迭代改进**来确保答案的准确性。

### 关键特点

1. **理解阶段**：先理解问题，制定策略
2. **执行阶段**：写代码、运行代码，得到答案
3. **验证阶段**：检查答案，发现错误就重做
4. **迭代循环**：直到答案正确或达到最大次数

### 为什么这样设计？

- **理解阶段**：避免盲目执行，提高效率
- **执行阶段**：用代码处理数据，准确可靠
- **验证阶段**：自动发现错误，提高质量
- **迭代循环**：不断改进，直到满意

这就是 SheetBrain 的完整工作流程！🎉
