# GUI Wireframe Designs
These wireframes were created to visualize and plan the user interface for the software application.
The primary goal was to establish a clear, intuitive layout that enhances the user experience by focusing on ease of navigation and accessibility.
The wireframes provide a layout for the software, showcasing how the user can interact with it, by mapping out these elements early in the design process,
we can ensure that the application’s structure aligns with user needs and project requirements before moving into development.

### Key Features
- Ability to upload .xlsx files for prompting the LLM
- Text input for prompting the LLM
- Settings page for toggling the mode

### Wireframe Design 1:
- **Description**: This design presents to the user a simple way to interact with the interface, providing text input for prompting the LLM as well as allowing an easy way of uploading .xlsx files by either browsing the user's desktop or dragging and dropping the file manually.
- **Tools Used**: Balsamiq

### Wireframe Design 2:
- **Description**: This design is similar to the first design, using a simple, easy-to-use layout that allows the user to upload their .xlsx files via drag and dropping or browsing the desktop. This design attempts to remove as much whitespace as possible, whilst also providing a larger area to input text prompts.
- **Tools Used**: Balsamiq
