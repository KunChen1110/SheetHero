# Technical Research
## Can an LLM Find Its Way Around a Spreadsheet? [link](https://vtechworks.lib.vt.edu/items/51d233b7-b566-4e55-9ba6-8f5d7ca8a256)
The study explores how Large Language Models can autonomously perform spreadsheet data cleaning and preprocessing, proposing a system architecture named **TradeSweep**.
![image](../../assets/OverviewOfTradeSweep_R1.png) 

### Workflow:
1.  In the **Prompt Augmentation** module, the user inputs the raw data and a request. 
2.  The system combines the request and the data into a vector embedding and uses it to search the **Code Library**, which stores multiple functions that can process the data. And each function in the library has a description generalised by GPT which informs what is the function of this function. 
3.  After selecting some relevant functions, the system combines the Top-k relevant codes with the retrieval prompt. In **Code Generation** module, **CodeLlama(LLM)** reads this prompt and creates a new function based on the functions and the request.
4.  After the automated assertion check, the user needs to check whether this output is correct, if it is correct, the system will store this new function into Code Library to make TradeSweep smarter.

### Prompt Augmentation:
1.  he system encodes the user’s natural-language request (e.g., “Clean dates to the same format”) into a vector embedding that represents its semantic meaning **(using Qdrant Library)**. 
2.	Each predefined function in the Code Library also has a vector representation and a short description generated by GPT.
3.	The system compares the request vector with all function vectors in the library using **cosine similarity**, and retrieves the **Top-k most relevant functions**.
4.	The selected Top-k functions, along with the user request and a sample of the data, are combined into a single prompt and sent to the LLM (CodeLlama). The LLM then generates a new Python function that fulfills the user’s request.

### Code Generation:
1.  The LLM create **code proposal** to accomplish the task based on the prompt which combining the candidate codes, data and user's request.
2.  LLM examines the code proposal whether it has some erros based on three criteria: **Incorrect code proposal format**, **Execution error** and **User's feedback**.
3.  After comfirming the code proposal is right, the system will provide entire output and the code will be applied to our code library to self-improving.
